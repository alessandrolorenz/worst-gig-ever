# M13.1 — Physical Re-Test Checklist

## Purpose

Validate whether the M13.1 ergonomic changes make the existing challenge easier to **read and control** without making it less fun.

Do not tune gameplay values before this re-test.

## Minimum

Play at least 6 rounds:

1. 2 rounds with one finger only;
2. 2 rounds with two fingers;
3. 1 Groove-focused round;
4. 1 natural/free-play round.

## Countdown

- Did `3 → 2 → 1 → GO` make the start clearer?
- Did the pulsing pad during countdown help you internalize the tempo?
- Did gameplay begin when you expected?
- Did any bottle appear too early?

## Pad placement

- Is the pad now easy to find without looking away from the center?
- Can you monitor bottles and the pulse in the same visual field?
- Does it feel like part of the drum kit rather than a UI button?
- Does the pad cover bottles or make final approach harder to read?

## Pad size

- Is it comfortably tappable?
- Is one-finger play more viable?
- Does the larger pad feel too easy or simply less awkward?
- Do you accidentally trigger Groove when aiming at nearby targets?

## Challenge

- Is Groove + Defense still difficult?
- Is it still fun?
- Does the challenge now feel more about coordination and less about searching for the pad?

## Input

- One finger: viable / awkward / impossible?
- Two fingers: natural / unnecessary / confusing?
- Any phantom taps?
- Any ignored taps?
- Any bottle/pad overlap that behaved strangely?

## Replay

After the re-test:

- Did you want another round?
- Did you improve across attempts?
- Did the countdown help you start better?
- Did centralizing the pad make the game feel more like one coherent task?

## Decision

Choose one:

- `M13_1_VALIDATED`
- `PAD_TOO_LARGE`
- `PAD_STILL_TOO_SMALL`
- `PAD_POSITION_NEEDS_TUNING`
- `COUNTDOWN_NEEDS_TUNING`
- `RHYTHM_DIFFICULTY_NEEDS_TUNING`
- `DEFENSE_DIFFICULTY_NEEDS_TUNING`
- `DUAL_TASK_NEEDS_TUNING`

Do not move to a second Groove Pad yet merely because the first version is validated.
