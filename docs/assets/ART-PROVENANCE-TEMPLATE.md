# Art Provenance

Record every production visual asset used by Worst Band Ever.

| Asset key | Local path | Source type | Tool/provider | Prompt file | Reference used | Generated/created date | Manual edits | Rights/licensing note |
|---|---|---|---|---|---|---|---|---|
| example | assets/art/... | generated/original | ... | prompts/assets/... | yes/no | YYYY-MM-DD | none/... | original/generated for project |

Rules:
- Do not leave provenance blank for a production asset.
- Do not use real band logos, celebrity likenesses, album art, or branded alcohol labels.
- Any externally sourced visual asset must record author, source URL, exact license, retrieval date, and original filename before integration.
