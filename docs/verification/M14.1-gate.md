## Findings and corrections

- **Confirmed feedback bug:** newly created strikes/bursts were immediately
  aged by the preceding frame delta. A 350ms frame could remove the 150ms
  strike and 280ms burst before either appeared. Existing effects, debris and
  stage motion now advance before new feedback is created. A regression test
  verifies new feedback starts at age zero even on that slow frame.
- **Oversized SVG raster surface:** the pad occupied a full 1920x1080 SVG.
  Installed `react-native-svg` 15.11.2 Android `SvgView.java` recycles its
  bitmap on invalidation and creates an ARGB bitmap at the native view size
  in `drawOutput`. A 664x234 surface, including stroke margin, preserves the
  exact ellipse with a matching viewBox and removes 92.5% of raster pixels.
  This cost predates M14; its contribution to the specific Galaxy regression
  has not been isolated with a native profiler.
- **Repeated image-tree work:** static layers and pose stacks are memoized.
  Changing props are scalar snapshots, not mutable domain objects, so pose
  changes still render. All approved ambient frames remain mounted.
- **Moving sprite layout:** targets, bursts, debris and strikes use fixed
  layout boxes with animated transforms. Geometry tests preserve centers,
  scales and rotation. Hit regions remain domain-owned and unchanged.
- **Image fade:** explicitly set to zero for scene assets. This is defensive,
  not a diagnosed release delay: installed RN 0.79 `ReactImageView.kt`
  already chooses zero for packaged resources unless explicitly overridden;
  its 300ms fallback applies to other source types.

Resolution did not grow with M14. All 33 canonical PNG dimensions are unchanged:
bottle 256x512 and mug 384x384. Compressed files decreased from 18.14MiB to
9.25MiB; summed decoded RGBA area remains 71.06MiB. No assets were resized or
replaced by this patch. No input timing, scoring, audio, engine, dependency,
spawn schedule or difficulty changes.

## Comparative browser probe

One before/after run each, same Chrome headless host, 960x540 viewport, Metro
development bundle, CDP 4x CPU throttling, 3-second start wait and 15-second
sampling window. Click centers of visible bottle/mug DOM images every 80ms;
no pad taps. CDP Performance metrics are window deltas. Both runs scored
1200 defense / eight hits and had zero page errors.

| Metric | M14 baseline | M14.1 |
| --- | ---: | ---: |
| ScriptDuration | 2.799s | 1.784s |
| TaskDuration | 3.872s | 2.959s |
| LayoutCount | 908 | 904 |
| RecalcStyleCount | 908 | 905 |
| RAF median / p95 | 16.7 / 16.7ms | 16.7 / 16.7ms |
| RAF intervals above 33.4ms | 0 | 0 |
| Pad SVG dimensions | 1920x1080 | 664x234 |

JavaScript time decreased approximately 36.3%; total task time decreased
23.6%. These are an instrumented single-run browser comparison, not Galaxy
measurements or a statistical benchmark. Both runs already maintained roughly
60fps; no FPS increase is claimed. React fiber instrumentation was also
present; recursive child flags can survive memo bailouts, so its descendant
counts are not reported as actual component executions.
