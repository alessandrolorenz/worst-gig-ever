# M13.1 Verification Gate

## 1. Repository / scope

Record:

- incoming branch;
- incoming HEAD;
- git status;
- files changed.

Confirm there is no unrelated owner work being discarded.

## 2. Static / automated gate

Run:

```sh
git diff --check
npm run type-check
npm run lint
npm test
npm run verify
npx expo export --platform android
npx expo export --platform web
```

All must pass.

## 3. Contract verification

Verify against `M13.1-test-matrix.md`.

Specifically confirm:

- no old two-beat count-in is stacked after the new countdown;
- countdown does not advance active round consequences;
- Groove first scored beat is one beat after GO;
- pad geometry is config-driven;
- non-interactive visual children remain excluded from touch targeting;
- M11 dual-resolution behavior still works;
- difficulty values are unchanged.

## 4. Difficulty-freeze diff

Claude must explicitly report old vs new values for:

- BPM;
- PERFECT/GOOD windows;
- target spawn cadence;
- target phase speeds;
- hit forgiveness;
- Show Integrity;
- vocalist timing;
- round duration;
- Groove score values;
- Defense score values.

Expected result:

`UNCHANGED`

If one changed, M13.1 gate fails unless the owner explicitly authorized it.

## 5. Geometry report

Report:

- old Groove Pad center;
- old visual size;
- old hit geometry;
- new center;
- new visual size;
- new hit geometry;
- reference-canvas safe bounds;
- target/pad z-order behavior.

## 6. Native smoke

When Android tooling is available:

- build/run using the known-good local workflow;
- do not use EAS;
- launch landscape;
- start round;
- observe 3/2/1/GO;
- confirm pad pulses;
- confirm no target before GO;
- confirm targets and pad work after GO;
- confirm no crash with alternating/rapid taps;
- background during countdown and confirm safe reset;
- restart and confirm countdown repeats.

If adb cannot meaningfully inject the engine's surface touch, report this limitation and rely on existing integration tests for touch behavior; do not claim physical touch success from a harness that cannot exercise it.

## 7. Result

PASS only if:

- automated gate green;
- difficulty freeze confirmed;
- countdown contract passes;
- geometry/input regressions absent;
- native objective smoke passes where testable.

Final state:

`READY_FOR_M13_1_RETEST`

## 8. Commit

If PASS, create local commit:

Do not push.
Do not run EAS.
