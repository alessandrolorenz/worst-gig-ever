# Global Rhythm Continuation Gate

Before continuing to the next milestone:

- current branch and HEAD recorded;
- worktree understood;
- prior milestone committed only after green gate;
- `git diff --check` clean;
- full `npm run verify` green;
- no hidden scope expansion;
- no remote Git/EAS mutation;
- no audio synchronization dependency;
- no store/monetization work;
- any architecture deviation documented in ADR/spec;
- current implementation still allows renderer-independent gameplay tests.

A failed gate blocks later milestones.
