# Worst Gig Ever — M14 Visual Refresh Patch

This patch replaces the earlier M14 visual-refresh direction.

## Why

The previous proposal leaned too far toward minimal poster/silhouette art.

The new direction aims for a **middle ground**:

- simpler and cleaner than the current detailed comic art;
- still expressive, character-driven, and visually rich enough to carry humor;
- readable at phone size;
- suitable for the existing low-frame animation system.
