# Worst Gig Ever — M13.1 Groove Readability & Entry Tuning

This package is a focused follow-up to the first physical M13 rhythm playtest.

## Owner playtest result

The rhythm pivot is promising.

Observed by the owner:

- Groove + Defense is **challenging but fun**.
- Keeping the groove while breaking bottles is meaningfully difficult.
- The difficulty itself is not currently considered a problem.
- The Groove Pad is too peripheral/small for the amount of attention the player must split.
- A larger lower-center Groove Pad should reduce unnecessary eye travel.
- A visible countdown before the round should make entry clearer.
- A second Groove area/pad is a good future difficulty idea, but must **not** be implemented now.

## M13.1 goal

Improve **readability, ergonomics, and entry** without reducing the actual gameplay challenge.

Do not change:

- BPM
- PERFECT/GOOD timing windows
- target speed
- target spawn cadence
- target hit forgiveness
- Show Integrity
- vocalist timing
- round duration
- existing Defense scoring
