# Production and review checklist

## Scope

- Only `marketing/` may change during this workstream.
- Initial non-marketing hashes include the owner's dirty working tree and previously started monetization dependency/config edits. Do not reset those changes.
- Run `node marketing/plans/check-isolation.mjs` and inspect `git diff` before delivery.
- Run existing type check, lint and automated tests per repository governance. Do not repair unrelated production files under this brief.

## Visual quality

- Inspect every generated master: recognizable cast, intended single action, correct instruments, no text/brand artifacts, readable at thumbnail size.
- Six portrait feed concepts; four independently recomposed vertical stories; hero landscape and square variants.
- Exact channel dimensions through proportional fit with a narrow charcoal matte if generator dimensions differ. No stretched faces, removed heads, missing instruments or important action crops.
- Preserve original generated files, including alternatives. Keep exact prompts and source references in `generated/prompts.json`.
- All files start REVIEW. Owner decisions are blank until KEEP / REVISE / REJECT is given. No approval is inferred from earlier production-art approval.

## Animation

- Four to six distinct key poses, 2–4 seconds, silent and readable.
- Export individual frames, animated WebP if supported, GIF fallback and sprite sheet.
- Check frame order, timing, size and return-to-first transition. Clearly label promotional animation, not game capture.

## Publication readiness (later)

- Apply owner revisions and choose KEEP assets.
- Add one language per composition; retain art-only originals.
- Use fresh actual gameplay captures for screenshot-based posts and store work.
- Verify a real download destination before replacing friend-test CTAs.
- No publication, account creation, website build or final store submission is part of this pack.
