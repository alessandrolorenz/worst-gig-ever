# Pack 1 Shared Visual Style Bible

Apply this style consistently to every Pack 1 generation request.

Game: **Worst Gig Ever** — humorous drummer-POV arcade game about surviving a chaotic rock show.

Visual language:
- simple 2D vector-like cartoon clip art;
- bold clean shapes/readable silhouettes;
- limited internal detail;
- flat color with light/simple shading only;
- slightly exaggerated proportions;
- energetic garage-rock/punk attitude;
- playful and chaotic, not violent or grim;
- intentionally compatible with low-frame retro animation;
- readable on a phone in landscape.

Palette:
- dark charcoal / blue-black / deep purple stage;
- saturated magenta, amber, teal, electric-blue lights;
- distinct performer clothing values;
- props contrast against crowd and performers.

Forbidden:
- photorealism;
- gore/injury;
- real band logos;
- celebrity likenesses;
- recognizable branded alcohol labels;
- album art;
- text baked into movable assets;
- complex background inside character/prop assets.

Character continuity:
For each character family create a canonical reference first. Preserve face/skin/hair, outfit, instrument, proportions, line weight, palette, camera angle, and approximate feet/ground anchor across all poses.

Ambient frames differ subtly; do not regenerate a different person.

All movable assets use transparent backgrounds. Main stage background is opaque. Lights/crowd remain separate layers.
