# V2 Drum Kit Sample Proof

Read `00-style-bible.md` first.

Use case: `stylized-concept`
Asset type: mobile game foreground-layer visual-direction proof
Input images:
- Image 1: candidate V2 performer lineup, style and simplification reference
- Image 2: current drummer-POV kit, perspective and component placement reference
Primary request: redraw the same drummer-eye kit composition in the Stylized
Punk Arcade Cartoon direction, cleaner and lighter than Pack 1.
Subject: battered red shells, warm gold cymbals, pale worn drum heads, dark
hardware; cymbals, toms, snare, and implied kick remain unmistakable.
Composition/framing: very wide drummer-POV foreground on one flat warm-gray
studio card; preserve
the large open central sightline; keep the lower-centre kick/snare area visually
calm for a code-drawn wide elliptical Groove Pad overlay; no drummer body.
Style/medium: exactly the same bold simplified arcade shape language as Image
1; clean 2D prop illustration; bold outer edges; simplified stands; broad
material shapes; one shadow tone; sparse controlled wear.
Constraints: no baked glow, rings, labels, UI, pulse, text, logos, brands, or
watermark; flat warm-gray background; preserve the existing viewpoint.
**No drumsticks anywhere in the image.** The runtime draws strike feedback from
the separate `drumstick` asset, and the first attempt painted a pair lying on
the snare — directly inside the lower-centre area reserved for the code-drawn
M13.1 Groove Pad ellipse. Leave that area bare.
Avoid: dense stand hardware, many dents, tape patches, grime speckles,
cross-hatched cymbal reflections, heavy foreground visual noise.
